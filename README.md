# 👁️ Clínica Visão Plena — Oftalmologia Especializada

Projeto desenvolvido como desafio prático da **Trilha HTML da [DIO.me](https://www.dio.me/)**. 

O objetivo do desafio é construir um site institucional completo para uma clínica médica fictícia utilizando **exclusivamente HTML puro** (sem uso de CSS externo ou inline), aplicando todos os conceitos fundamentais abordados no módulo.

---

## 📋 Sobre o Projeto

A **Clínica Visão Plena** é uma clínica fictícia especializada em Oftalmologia. O site conta com navegação entre 4 páginas principais, identidade visual própria desenvolvida com gráficos vetoriais (`SVG`) e layout estruturado seguindo o template proposto pelo desafio.

### Páginas do Site
* **Página Principal (`index.html`):** Apresentação da clínica, slogan, destaques e chamada para agendamento.
* **Sobre a Clínica (`sobre.html`):** História, missão, infraestrutura e corpo clínico.
* **Horário de Atendimento (`horario.html`):** Tabela detalhada com serviços, horários de funcionamento por dia da semana, valores e orientações aos pacientes.
* **Contato (`contato.html`):** Telefones, WhatsApp, endereço completo, mapa interativo incorporado via Google Maps e formulário funcional de contato.

---

## 🛠️ Conceitos e Tags HTML Aplicados

* **Estruturação Semântica:** `<header>`, `<nav>`, `<main>`, `<footer>`, `<fieldset>`, `<legend>`.
* **Formatação e Hierarquia de Texto:** `<h1>` a `<h3>`, `<p>`, `<strong>`, `<em>`, `<u>`, `<mark>`, `<blockquote>`, `<small>`, `<hr>`, `<ul>`, `<li>`.
* **Mídias:** Logotipo e banners exclusivos para cada cabeçalho em formato vetorial (`<img src="*.svg">`) e incorporação de mapa externo (`<iframe>`).
* **Tabelas:** Estruturação de layout base e tabela de horários/valores utilizando `<table>`, `<thead>`, `<tbody>`, `<tr>`, `<th>` e `<td>`.
* **Formulários:** Campos tipados e acessíveis com `<form>`, `<label>`, `<input type="text">`, `<input type="email">`, `<textarea>`, `<button type="submit">` e `<button type="reset">`.
